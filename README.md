# DT Academy - Login Instructions

This document provides the credentials and instructions for logging into the DT Academy portal with different user roles. 

## 1. Admin (Director) Login

The Admin portal is fully secured and requires exact credentials to access the school management features.

- **Email:** `director@dt-academy.local`
- **Password:** `ChangeMeNow!`

*Note: Entering an incorrect password for the admin account will correctly display an "Invalid email or password" error.*

---

## 2. Temporary Testing (Demo Fallback)

To make it easy for developers, staff, or testers to explore the Parent and Student portals without needing to memorize specific demo accounts, we have implemented a **temporary fallback sign-in feature**.

If you attempt to log in with an email address that does **not** match the Director's email, the system will automatically intercept the login and route you to a demo account behind the scenes.

### How to test the Student Portal:
- **Email:** Enter any email containing the word **`student`** (e.g., `teststudent@gmail.com` or simply `student`).
- **Password:** Enter any text.
- **Result:** You will be logged in automatically as the demo student (`dt-2026-0001@students.dt-academy.local`).

### How to test the Parent Portal:
- **Email:** Enter any random email or text (e.g., `parent@test.com` or just `test`). *Just make sure it does not contain the word "student" and is not the director's email.*
- **Password:** Enter any text.
- **Result:** You will be logged in automatically as the demo parent (`family@demo.dt-academy.local`).
